# Consciousness — HTML Web Package

Author: Bienuel C. Tenio

Open dist/index.html in a web browser. Upload the contents of dist/ to the root of any static web host (including Netlify).

The package contains nine HTML pages: the introduction, seven individual book guides, and the author biography. All pages share assets/style.css. The pages work without JavaScript; web fonts are optional and fall back to local fonts offline.

Book order follows the requested sequence. Book descriptions and chapter guides are based on the seven supplied 2025 PDFs. The PDF page totals refer to the files, rather than printed page numbers. The Dream Consciousness final chapter descriptions follow its table of contents. Source PDFs are not included or publicly distributed in this package.

The biography uses supplied personal background. It does not claim scientific or clinical credentials. books.json contains the structured book information for future editing.
